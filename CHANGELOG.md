# Changelog

All notable changes to Thompson are recorded here. Thompson follows Semantic Versioning.

## 0.1.0 - 2026-09-06

### Added

- Initial public React Native design-system package with Bleecker-aligned contracts, themes, components, layouts, charts, rich-text support, and native assets.
- Expo component gallery and on-device Storybook coverage.
- Strict Bleecker parity, contract, type, build, test, story, package-content, and clean-consumer gates.
- Reproducible release workflow with provenance, checksummed npm artifact, and immutable GitHub release enforcement.
