# Thompson v0.1.0

Thompson v0.1.0 is the first versioned release of Gaulatti's React Native design system. It turns the previously commit-pinned package into an immutable npm dependency.

Highlights:

- Bleecker-aligned native components, layouts, contracts, themes, and tokens
- Expo component gallery and device Storybook
- Native chart, rich-text, administration, navigation, data-display, form, and feedback primitives
- strict Bleecker parity and Storybook coverage gates
- deterministic package-content and clean-consumer verification

Install the exact release with `npm install @gaulatti/thompson@0.1.0`. See `docs/RELEASING.md` for the compatibility matrix and operational policy.
